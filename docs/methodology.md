# 방법론

## 1. 유사도 검색엔진 목적

이 프로젝트는 뉴스 포털 또는 뉴스 섹션 링크에서 여러 기사를 수집한 뒤, 기준 메인 기사와 내용이 비슷한 기사를 찾는 유사도 검색엔진이다.

기본 방식은 사용자가 메인 기사 링크를 직접 지정하고, 포털에서 수집한 기사들을 그 메인 기사와 비교하는 것이다. 메인 기사 링크를 지정하지 않는 자동 모드에서는 수집된 기사 중 다른 기사들과 평균적으로 가장 많이 비슷한 기사를 메인 기사로 선정한다.

## 2. 전처리와 형태소 분석

전처리는 다음 순서로 진행한다.

1. 기사 제목과 본문을 결합한다.
2. `kiwipiepy`가 설치되어 있으면 Kiwi 형태소 분석기로 명사, 동사, 외국어 토큰을 추출한다.
3. 형태소 분석기가 없으면 정규식 기반 토큰화로 대체한다.
4. 조사, 접속어, 기사 관용어 등 분석에 불필요한 불용어를 제거한다.

형태소 분석을 사용하는 이유는 한국어에서 조사와 어미가 단어 뒤에 붙어 의미 단위 추출을 어렵게 만들기 때문이다. 형태소 분석은 표면형 차이를 줄여 키워드와 유사도 계산의 품질을 높인다.

## 3. 유사도 검색 방법론

### 3.1 TF-IDF 벡터화

각 기사는 토큰 목록으로 변환한 뒤 TF-IDF 벡터로 표현한다.

- TF: 한 기사 안에서 특정 단어가 얼마나 자주 등장하는지
- IDF: 모든 기사에 흔히 등장하는 단어의 영향력을 낮추고, 특정 기사군에서 구분력이 있는 단어의 영향력을 높이는 값

따라서 TF-IDF는 단순 빈도보다 "문서 구분에 중요한 단어"를 더 잘 반영한다.

### 3.2 코사인 유사도

두 기사 벡터의 방향이 얼마나 비슷한지 코사인 유사도로 계산한다. 값은 1에 가까울수록 단어 사용 패턴이 비슷한 기사라고 볼 수 있다.

이 프로젝트에서 코사인 유사도는 다음에 사용된다.

- 사용자가 지정한 메인 기사와 후보 기사 사이의 유사도 순위 계산
- 자동 선정 모드에서 기사 간 유사도 행렬 생성
- 자동 선정 모드에서 메인 기사와 다른 기사 사이의 유사도 순위 계산

### 3.3 메인 기사 지정 및 선정

직접 지정 모드에서는 사용자가 입력한 메인 기사 URL의 본문을 기준 문서로 고정한다. 이후 포털/섹션 링크에서 수집한 후보 기사들을 기준 문서와 각각 비교하고, TF-IDF 코사인 유사도가 높은 순서대로 정렬한다.

자동 선정 모드에서는 모든 기사 쌍의 TF-IDF 코사인 유사도를 계산한 뒤, 각 기사마다 다른 기사들과의 평균 유사도를 구한다. 평균 유사도가 가장 높은 기사는 전체 기사 묶음에서 중심성이 가장 높은 문서로 해석할 수 있으므로 메인 기사로 선정한다.

### 3.4 Jaccard 유사도 검증

Jaccard 유사도는 두 기사 토큰 집합의 교집합과 합집합 비율이다.

TF-IDF 코사인 유사도는 단어 중요도와 빈도를 반영하고, Jaccard는 단어가 겹치는 정도를 단순하게 보여준다. 둘을 함께 보면 높은 유사도가 단순 우연인지, 실제로 공유 단어가 많은지도 확인할 수 있다.

따라서 Jaccard는 메인 검색 알고리즘이 아니라 유사도 검증용 보조 지표로 사용한다.

## 4. 핵심 키워드 추출

핵심 키워드는 메인 기사와 관련 기사들의 TF-IDF 점수를 합산해 추출한다. 여러 기사에서 반복되면서도 일반적인 단어가 아닌 토큰은 높은 점수를 받는다.

출력 예시는 다음과 같다.

```text
인공지능: 0.0832
반도체: 0.0698
생성형: 0.0521
데이터센터: 0.0494
```

## 5. Word2Vec 유사도 검증

Word2Vec은 단어의 주변 문맥을 이용해 단어를 벡터로 학습한다. 이 프로젝트에서는 수집된 기사 토큰을 문장 집합으로 보고 Skip-gram 방식으로 Word2Vec을 학습한다. Python 3.14에서 `gensim` 빌드가 실패할 수 있으므로, 시연 안정성을 위해 프로젝트 내부에 순수 Python Skip-gram 학습기를 포함했다.

검증 방식은 다음과 같다.

1. TF-IDF로 뽑은 핵심 키워드 상위 몇 개를 기준 단어로 선택한다.
2. Word2Vec 모델에서 기준 단어와 가장 가까운 단어를 찾는다.
3. 기준 단어와 주변 단어의 코사인 유사도를 출력한다.

예시는 다음과 같다.

```text
기준 키워드: 인공지능
유사 단어: 생성형 0.82
유사 단어: 데이터센터 0.76
유사 단어: 반도체 0.71
```

이 결과는 핵심 키워드가 기사 묶음 안에서 어떤 단어들과 의미적으로 가까운지 보여준다. TF-IDF가 중요한 단어를 고르는 방법이라면, Word2Vec은 그 단어 주변의 의미 관계를 검증하는 방법이다.

## 6. 한계와 개선 방향

- 포털마다 HTML 구조가 달라 본문 추출 성능이 달라질 수 있다.
- 기사 수가 너무 적으면 Word2Vec 학습 품질이 낮다.
- 더 정확한 서비스형 검색엔진으로 확장하려면 문장 임베딩 모델, 중복 기사 제거, 언론사별 본문 파서가 필요하다.
