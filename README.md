# 뉴스 유사도 검색 엔진

메인 기사 링크와 포털/섹션 링크를 입력하면, 포털/섹션에서 수집한 후보 기사들을 메인 기사와 비교해 유사도 순으로 정렬하는 Streamlit 기반 뉴스 분석 프로젝트입니다.

## 전체 흐름

1. 사용자가 기준 메인 기사 링크와 비교할 포털/섹션 링크를 입력합니다.
2. 메인 기사에서 제목과 본문을 수집합니다.
3. 포털/섹션 페이지에서 후보 기사 링크를 수집합니다.
4. 후보 기사들의 제목과 본문을 수집합니다.
5. 기사 본문에서 광고, 추천 문구, 저작권 문구 등 노이즈를 제거합니다.
6. 제목과 본문을 토큰화하고 불용어, 조사, 어미를 제거합니다.
7. TF-IDF 벡터와 Word2Vec 문서 벡터를 생성합니다.
8. 여러 유사도 지표를 가중합해 종합 유사도를 계산합니다.
9. 종합 유사도가 높은 순서로 후보 기사를 출력합니다.
10. 핵심 키워드와 Word2Vec 기반 유사 단어를 함께 보여줍니다.

## 주요 방법론

### 1. 토큰화와 전처리

기사 원문을 그대로 비교하지 않고, 분석에 필요한 단어 중심으로 정리합니다.

- 한글, 영문, 숫자 기반 토큰 추출
- 조사 제거
- 어미 제거
- 불용어 제거
- 영문 키워드 대문자 정규화
- 복합어 보강

예를 들어 `인공지능반도체`처럼 붙어 있는 단어는 다음처럼 보강합니다.

```text
인공지능반도체
인공지능
반도체
```

이렇게 하는 이유는 기사마다 `인공지능 반도체`처럼 띄어 쓰거나 `인공지능반도체`처럼 붙여 쓰는 차이가 있기 때문입니다. 복합어를 보강하면 같은 주제의 기사를 더 잘 매칭할 수 있습니다.

### 2. TF-IDF

TF-IDF는 각 기사에서 중요한 단어를 찾기 위한 정보검색 방법입니다.

- TF: 한 문서 안에서 특정 단어가 얼마나 자주 나오는지
- IDF: 전체 문서에서 너무 흔한 단어의 중요도를 낮추는 값

뉴스에는 `기자`, `오늘`, `관련` 같은 일반 표현이 많이 나오므로 단순 단어 빈도만으로는 주제를 판단하기 어렵습니다. TF-IDF를 사용하면 `인공지능`, `반도체`, `데이터센터`처럼 기사 주제를 잘 나타내는 단어에 더 높은 가중치를 줄 수 있습니다.

### 3. 코사인 유사도

TF-IDF로 만든 기사 벡터 사이의 유사도를 계산할 때 코사인 유사도를 사용합니다.

코사인 유사도는 벡터의 크기보다 방향을 비교합니다. 뉴스 기사는 길이가 서로 다르기 때문에 단순 공통 단어 개수만 비교하면 긴 기사가 유리해질 수 있습니다. 코사인 유사도는 기사 길이에 덜 영향을 받으면서 핵심 단어 분포가 얼마나 비슷한지 비교할 수 있습니다.

이 프로젝트에서는 다음 두 곳에 사용합니다.

- 메인 기사 본문 TF-IDF 벡터와 후보 기사 본문 TF-IDF 벡터 비교
- 메인 기사 제목 TF-IDF 벡터와 후보 기사 제목 TF-IDF 벡터 비교

### 4. 메인 핵심어 포함률

메인 기사에서 TF-IDF 점수가 높은 핵심 단어를 뽑고, 그 단어들이 후보 기사에 얼마나 포함되어 있는지 계산합니다.

같은 사건이나 주제를 다루는 기사라면 메인 기사의 핵심 키워드가 후보 기사에도 어느 정도 등장해야 하므로, 이 값을 종합 유사도에 반영합니다.

### 5. Jaccard 유사도

Jaccard 유사도는 두 기사에서 나온 단어 집합이 얼마나 겹치는지 보는 지표입니다.

```text
겹치는 단어 수 / 전체 단어 수
```

TF-IDF와 코사인 유사도는 단어 중요도를 반영하는 장점이 있고, Jaccard 유사도는 실제 단어 집합의 겹침을 직관적으로 보여주는 장점이 있습니다. 이 프로젝트에서는 Jaccard를 보조 지표로 사용합니다.

### 6. Word2Vec

Word2Vec은 단어를 벡터로 표현하는 방법입니다. 비슷한 문맥에서 자주 등장하는 단어들은 벡터 공간에서 가까운 위치를 갖습니다.

이 프로젝트에서는 Word2Vec을 두 가지 방식으로 사용합니다.

첫째, 기사 유사도 계산에 사용합니다. 기사 안의 단어 벡터들을 평균내서 기사 문서 벡터를 만들고, 메인 기사 문서 벡터와 후보 기사 문서 벡터의 코사인 유사도를 계산합니다.

```text
기사 토큰
→ 단어별 Word2Vec 벡터
→ 평균 문서 벡터
→ 문서 벡터 간 코사인 유사도
```

둘째, 핵심 키워드별 유사 단어를 출력합니다. 예를 들어 핵심 키워드가 `AI`라면 Word2Vec 모델에서 가까운 단어를 찾아 결과 화면 아래에 함께 보여줍니다.

Word2Vec만 단독으로 사용하지 않고 TF-IDF와 함께 사용하는 이유는, Word2Vec은 의미적 관계를 볼 수 있지만 기사 수가 적을 때 불안정할 수 있기 때문입니다. 따라서 TF-IDF 중심의 설명 가능한 점수에 Word2Vec 의미 유사도를 보조로 결합했습니다.

## 종합 유사도 계산

최종 기사 순위는 하나의 지표만 사용하지 않고 여러 점수를 가중합해 계산합니다.

```text
종합 유사도 =
본문 TF-IDF 코사인 유사도
+ 제목 TF-IDF 코사인 유사도
+ 메인 핵심어 포함률
+ Jaccard 유사도
+ Word2Vec 문서 유사도
```

현재 가중치는 다음과 같습니다.

| 지표 | 가중치 | 사용 이유 |
| --- | ---: | --- |
| 본문 TF-IDF 코사인 유사도 | 54% | 기사 본문 내용의 핵심 유사도 |
| 제목 TF-IDF 코사인 유사도 | 18% | 같은 사건/주제 여부 보강 |
| 메인 핵심어 포함률 | 11% | 메인 기사 핵심 키워드 반영 |
| Jaccard 유사도 | 5% | 실제 단어 집합 겹침 보조 |
| Word2Vec 문서 유사도 | 12% | 의미적으로 가까운 단어 관계 보완 |

## 핵심 코드 위치

주요 로직은 `news_similarity_engine.py`에 있습니다.

| 함수 | 역할 |
| --- | --- |
| `tokenize()` | 기사 본문과 제목을 분석용 토큰으로 변환 |
| `compute_tfidf_vectors()` | 기사별 TF-IDF 벡터 생성 |
| `cosine_similarity()` | TF-IDF 벡터 및 문서 벡터 간 코사인 유사도 계산 |
| `main_keyword_coverage()` | 메인 기사 핵심어가 후보 기사에 포함되는 비율 계산 |
| `jaccard_similarity()` | 단어 집합 겹침 정도 계산 |
| `document_word2vec_vectors()` | 기사별 Word2Vec 평균 문서 벡터 생성 |
| `word2vec_keyword_neighbors()` | 핵심 키워드별 Word2Vec 유사 단어 추출 |
| `blended_similarity_score()` | 여러 점수를 가중합해 최종 유사도 계산 |
| `rank_against_main_article()` | 메인 기사와 후보 기사들을 비교해 순위 생성 |

## 실행 방법

필요 패키지를 설치합니다.

```bash
python -m pip install -r requirements.txt
```

Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```

또는 가상환경을 사용하는 경우:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

샘플 데이터로 CLI 분석을 실행할 수도 있습니다.

```bash
python news_similarity_engine.py --sample
```

## 발표용 요약

이 시스템은 메인 기사와 포털/섹션에서 수집한 후보 기사들을 비교하여 유사한 기사를 찾는 뉴스 유사도 검색 엔진입니다. 기사 제목과 본문을 수집한 뒤, 한국어 토큰화 및 불용어 제거, 조사/어미 제거, 복합어 보강을 수행합니다. 이후 TF-IDF 벡터와 Word2Vec 문서 벡터를 생성하고, 본문 코사인 유사도, 제목 코사인 유사도, 메인 핵심어 포함률, Jaccard 유사도, Word2Vec 문서 유사도를 결합해 최종 종합 유사도를 산출합니다. Word2Vec은 문서 간 의미적 유사도 계산과 핵심 키워드별 유사 단어 출력에 활용됩니다.
